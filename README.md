# sass-reset

> reset stylesheet for sass

![](https://img.shields.io/github/license/bamdadfr/sass-reset)
![](https://img.shields.io/github/v/release/bamdadfr/sass-reset)

## installation

```bash
pnpm add sass-reset
```

## examples

### `.scss` file

```scss
@import '~sass-reset';
```

### `.js` file

```javascript
import 'sass-reset';
```
